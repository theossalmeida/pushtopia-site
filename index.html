The loop

A simple rhythm for your day.

Connect a GitHub account in the macOS app and choose repositories to monitor. Pushtopia checks GitHub on a rate-aware schedule and can also watch folders you configure locally. No webhooks or repository hooks are installed.

  1. 01

    Sign in on your Mac

    Authorize Pushtopia through GitHub Device Flow. The token stays in macOS Keychain; access depends on the permissions you grant.

    $ open -a Pushtopia # → enter code ABCD-1234
  2. 02

    Pick your repos

    Choose repositories from those your GitHub authorization can access. You can also configure local folders for push detection.

    watching acme/api · acme/web · you/dotfiles
  3. 03

    Keep building

    GitHub checks and optional local folder monitoring detect eligible activity. A local commit alone does not count as a push.

    push ▸ needs · XP · streaks
  4. 04

    Care for your pet

    See your pet’s needs, mood, level and streaks in the menu bar and pet window. Activity details are not presented as a saved feed.

    needs · level · contribution · green CI

Privacy by default

Your code stays yours.

This site does not access your GitHub account. Sign-in happens in the macOS app through GitHub Device Flow. GitHub activity and pet progress are processed on your Mac; if you opt into account sync, limited pseudonymous progress data is sent to our backend so it can be recovered on another Mac. When configured, minimal app-open analytics is on by default and can be disabled in Settings. No webhooks or repository hooks are installed.
